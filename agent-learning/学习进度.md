## 环境/代码注意事项

- API Key 放在 `agent-learning/.env`，格式为 `DEEPSEEK_API_KEY=sk-...`；`.env` 已加入 `.gitignore`。
- 新电脑克隆仓库后，如果 `.venv` 不随 Git 同步（正常不会同步），需要重建环境：

  ```bash
  uv venv .venv
  uv pip install --python .venv/bin/python openai-agents python-dotenv
  ```

  （`openai` 会作为 `openai-agents` 的依赖自动安装。）
- 模型统一用 `deepseek-flash`，不要写 `gpt-*` 模型名。
- 遇到“没有找到 DEEPSEEK_API_KEY”：确认 `agent-learning/.env` 存在且内容格式正确；
  若仍报错，检查是否安装 `python-dotenv`。
- 遇到 `ModuleNotFoundError: No module named 'agents'`：安装 `openai-agents` 后再运行。
- 运行脚本前先验证环境：

  ```bash
  cd 仓库目录
  python agent-learning/00_first_api_call.py
  python agent-learning/01_hello_agent.py
  python agent-learning/02_agent_with_tool.py
  ```
