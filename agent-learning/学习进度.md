### 动手前先知道这八条（都是本阶段真踩过的）

1. **模型评估由用户在自己时段跑**（会花 token）；AI 侧只跑 `--unit-only` 与离线测试。
   10 条一轮实测约 39 万 token（67 次请求），低谷价粗估 0.25~0.3 元；
2. **重活放低谷**：工作日 12:00–14:00、18:00–次日 09:00、周末全天，价格是高峰的一半；
3. **不要用 `git checkout --` / `git restore` 清临时改动**——它是文件级的，会把该文件
   **所有**未提交改动一起冲掉，而且不报错（台账 T9 的现场）；
4. **无答案题的关键词不能写进 `agent-learning/*.md`**——那等于把答案卡交给被检索的 Agent
   （台账 T8"发现一"）。题库与答案卡只写在 `notes-qa/` 内（该目录已在 `EXCLUDE_DIRS` 中）；
5. 未经用户明确要求**不要 `git commit` / `git push`**（仓库规则）。
6. **要"改坏代码做验证"，就复制到临时目录改**——第 14 周的变异测试（T13）就是这么做的；
   直接在仓库里改再还原，很容易变成 T9 那种事故；
7. **`ruff --fix` 之后必须重跑 `ruff check`**：它会删掉写法不规范的 `# noqa`，
   也可能把改动留在你没预期的地方（T12）；
8. **验证类脚本的输出要限流**（`| cut -c1-100`）：旧入口会把整个文件内容打进 FAIL 行，
   一次变异测试的输出能爆到 26 万 token（T14 附近记录）。

## 环境/代码注意事项

- Python 版本要求 **≥3.12**：`notes-qa/main.py` 用了 `asyncio.timeout`（需 3.11+），`notes-qa/eval_cases.py` 用了 `Path.is_junction()`（需 3.12+）。文档早期写的"Python 3.10+"是错的，本机实际使用 3.14.4。
- API Key 放在 `agent-learning/.env`，格式为 `DEEPSEEK_API_KEY=sk-...`；`.env` 已加入 `.gitignore`。
- 新电脑克隆仓库后，如果 `.venv` 不随 Git 同步（正常不会同步），需要重建环境：

  ```bash
  uv venv .venv
  uv pip install --python .venv/bin/python openai-agents python-dotenv
  ```

  （`openai` 会作为 `openai-agents` 的依赖自动安装。）
- 模型统一用 `deepseek-flash`，不要写 `gpt-*` 模型名。
- 遇到“没有找到 DEEPSEEK_API_KEY”：确认 `agent-learning/.env` 存在且内容格式正确；
  若仍报错，检查是否安装 `python-dotenv`。
- 遇到 `ModuleNotFoundError: No module named 'agents'`：安装 `openai-agents` 后再运行。
- 运行脚本前先验证环境：

  ```bash
  cd 仓库目录
  python agent-learning/00_first_api_call.py
  python agent-learning/01_hello_agent.py
  ```
