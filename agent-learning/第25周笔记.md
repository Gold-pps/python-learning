## 2. T44：手写夹具把一条走不到的分支测成了绿的

**现象**：把前端冒烟的视图从"手写"换成"从真实 `ask()` 产物派生"之后，冒烟**当场变红**——
真数据里只有 **2** 个可点引用标签，而手写夹具里是 3 个。第三条"回查不到"（编造档）
**在真实数据里从来没出现过**。

**根因是两层**，两层都值得记：

- 代码侧：`validate_citations()` 会把编造引用**从条目上摘掉**（只进 `citation_invalid` 计数），
  所以界面上那条"红底 = 回查不到"是**兜底分支**；
- 文档侧：而**文档把它写成了常规展示**——使用说明里那句"红底 = 回查不到……
  已单独计数，但没有被静默删掉"，后半句与代码相反。

**改法**（对齐到"代码是对的、文字是错的"）：

1. `validate_citations` 的 docstring 按**代码口径**重写：摘掉才对——挂在结论上的引用意味着
   "这条结论有出处"，而编造的出处不是出处；同时把"看得见"的定义写清（计数 + 逐条列出）；
2. 界面补上**逐条列出编造引用**那一块（CLI 报告早就有，界面此前只有计数：
   只给计数等于"知道有问题、不知道哪条有问题"）；
3. 兜底分支加注释说明"正常路径走不到"；冒烟里那条红底断言改成**断言它不该出现**，
   另用一份手造数据单独验"兜底不会崩"。

**附带收益**：那条漂移检测测试上线就抓到两处漏归一化的字段（`generated_at`、
`retrieval[].elapsed_s`），后来改 `top_k` 时又抓到视图里 `top_k` 从 5 变 8——
**"改了代码 → 夹具测试变红 → 重新生成"** 这条工作流真的在用。

## 3. 免费的一步追平付费的一步

同一批 20 题、同一索引 `data/index-notes`，三次离线复测（不花 token）：

| 混合（RRF）严格判据 | k=5 | k=8 | k=8 + 查询侧过滤 |
| ------------------- | --- | --- | ---------------- |
| 有答案（10）        | 5/10 | 6/10 | **7/10** |
| 跨文档（5）         | 0/5 | 1/5 | **2/5** |
| 多跳（5）           | 2/5 | 2/5 | **3/5** |
| **合计（20）**      | 7/20 | 9/20 | **12/20** |
| 关键词基线          | 1/20 | 1/20 | 1/20 |

两处改动：

1. **深度**：`DEFAULT_TOP_K` 5 → 8。提升集中在"有答案"类——病征是"**找对了文档、找不到那一段**"
   （正确答案在同一篇的靠后片段里，k=5 排不下）；
2. **查询侧过滤**：新增 `tokenize_query()`，只作用于**查询**——丢虚词与疑问词，
   并在"多字词还剩 ≥2 个"时丢单字（"轴的热误差"里的"轴"是有信息的，不能丢）。
   **索引侧切词一字不动**：动它等于换 BM25 的统计口径，会作废全部历史数字。

**为什么说"追平"**：第 19 周那 12/20 是"混合 + 重排"（每题多一次模型调用）拿到的，
而且当时因为 5 次调用被 `max_tokens` 截断、退化成不重排，那个数还只是**下界**。
现在这 12/20 是**离线、不加调用、不加时间**拿到的，分布也略有不同（多跳 3/5 vs 2/5）。

## 4. 定论：RRF 分数不能当"可分性"判据

遗留 #3 要求把 `RERANK_GAP` 改成"切分点视角"。查完代码后的结论是**不改阈值**：

- 现状是"窗口内最小相邻分差 < 0.01 才重排"，而 **RRF 分数是排名组合的函数、大量并列** →
  相邻分差常为 0 → 判据**恒触发**；
- 关键判断：**这不是"阈值没调对"**。RRF 分数只在"谁在几路里排第几"这个层面携带信息，
  它**不携带"可分性"**——基于它做任何阈值都是在看噪声。要真做对得换信号
  （两路召回一致性、分数落差），而那需要**带标注的重排数据**校准，本阶段没有（得花钱真跑）；
- 而现行行为（总是重排）实测**值这个钱**（第 19 周：7/20 → 12/20）。

所以：**行为不动，把"成本控制"这句不成立的承诺从描述里去掉**，方向登记在案；
并加了一条测试把"RRF 并列 → 恒触发"这个性质钉住——它是有意保留的已知行为，不是漏改。

## 5. 另一条定论：解析层"整页判定"不做

T36 留的说法是"有些文献页每片段特征太少，页级表决也补不上，根治要在解析层按整页判定再下传"。
本周判定**不做**，三条理由：

1. **收益面窄**：T36 换判据后已把误标从"26.6% 的正文页"降到 **657/2501** 且集中在论文末尾；
2. **代价不小**：要改解析/切分/索引三处并**重建索引**（101~118s），
   而且会让第 20~22 周与 `is_reference` 有关的**所有数字一次性作废**，得重跑一轮衡量；
3. **顺序不划算**：第三阶段 H2（MCP）/H3（可核对）的收益比它大得多。

**影响范围写清**：少数文献页的**正文片段**可能仍被判成"参考文献段"而不进候选，
表现为"某一页的正文怎么问都不在候选里"；要复现含文献表的检索，加 `exclude_references=False`。
真要做，必须与"重建索引 + 重跑那批数字"**作为一个整体**安排，不能顺手改。
