# 10 分钟演示稿：从零做出一个笔记问答 Agent

> 用途：组会汇报 / 演示底稿
> 时长：10 分钟（含 1 分钟现场演示）

## 时间分配

| 部分       | 时长  | 内容                               |
| ---------- | ----- | ---------------------------------- |
| 开场       | 1 min | 一句话说清做了什么                 |
| 背景与目标 | 1 min | 为什么要学 Agent                   |
| 学习路线   | 2 min | 12 周做了什么                      |
| 项目演示   | 3 min | notes-qa 现场问答（含 1 min demo） |
| 关键收获   | 2 min | 3 个技术点                         |
| 下一步     | 1 min | 想继续做的方向                     |

---

## 第 1 部分：开场（1 min）

**一句话**：

> 我用 12 周，从"不会调 API"做到一个能读本地笔记、会自己找资料、会引用来源、
> 找不到就说找不到的问答助手。

**要点**：

- 全程用 DeepSeek API，没有 OpenAI 充值；
- 开发框架是 OpenAI Agents SDK，但请求全部发往 DeepSeek；
- 最终产物是一个命令行工具，能问本地 Markdown 笔记。

---

## 第 2 部分：背景与目标（1 min）

**为什么学 Agent**：

- 大模型不只是聊天，它可以"主动工作"；
- Agent = 模型 + 指令 + 工具 + 循环 + 状态；
- 想搞明白这套东西怎么落地，所以动手做一个。

**目标**：

- 12 周完成一个能用的 Agent 小项目；
- 每周一个可运行的产出，不只看文档。

---

## 第 3 部分：学习路线（2 min）

**前 7 周：打基础**（每周一个脚本）

- 第 1~2 周：配置环境，跑通第一个 Agent；
- 第 3 周：让 Agent 学会使用工具；
- 第 4 周：理解多轮对话怎么保留上下文；
- 第 5 周：多个 Agent 之间的交接；
- 第 6 周：加护栏和人工审批；
- 第 7 周：本地日志、评估用例、账单管理。

**第 8~11 周：做项目**

- 第 8 周：定范围，画结构；
- 第 9 周：最小可用版本；
- 第 10 周：交互升级 + 安全修复；
- 第 11 周：写 AGENTS.md、做 Skill、接 MCP。

**第 12 周：复盘**（本周）。

---

## 第 4 部分：项目演示（3 min）

### 项目是什么

`notes-qa`：个人笔记问答助手。

### 怎么工作

```text
用户问题
  → Agent 决定搜索
  → search_notes 关键词搜索
  → 必要时 read_note 读取上下文
  → 基于原文回答 + 引用来源
  → 找不到就说"笔记中没有找到"
