# 第 22 周笔记：真实使用与定向优化（G3 验收）

日期：2026-10-09

## 一句话结论

本周把系统交给**真实需求**：题目不是我拟的，而是从使用者的
《AI+智能制造联合创新实验室建设实施方案》里挑出来的。三次使用 **2 次采纳、1 次"帮倒忙"**，
而最有价值的三条结论都不是"答得好"：

1. **问之前先摸底，比答得好更重要**：先做了一轮离线关键词覆盖——
   方案里想要的"大模型辅助工艺编制 / NC 程序检查 / 案例检索"，本库覆盖是 **0**。
   于是第 3 题变成**故意的缺口探针**，它的"答不出来"直接告诉使用者第二期该收什么资料；
2. **引用校验能保证"没编"，保证不了"没用错"**：三次共 50 条引用、代码校验 0 编造、
   抽查 5 条数值逐字对得上——但人工读的时候发现三处**语境漂移**（超精密慢伺服参数、
   转引、RL 智能体 ≠ LLM 智能体）。**"回查通过"和"能直接用"是两回事**；
3. **判据写错的时候，它自己就是噪声源**：参考文献段标记的第一版判据把 **26.6% 的片段**
   标成了参考文献（中文综述正文里"某某等[18]提出"满篇都是）。教训是
   **特征要挑"目标里几乎不会出现、而噪声里才有的"**，而不是"看起来相关就行"。

> 逐条"现象 → 根因 → 改法 → 验证"见 `工程化改造记录.md` T35 / T36；
> 使用记录见 `eval/使用记录-0{1,2,3}.md` 与 `data/usage_log.jsonl`（不进 Git）。

## 2. 关键设计

### 2.1 先摸底再出题：方案要什么 vs 语料有什么

拿到方案后做的第一件事不是出题，而是**查本库能不能答**（离线、纯 BM25，几秒钟）：

| 方案模块 | 语料覆盖 | 判断 |
| -------- | -------- | ---- |
| 大模型与智能体辅助模块 | 关键词 **0 片段** | ❌ 本库答不了 |
| NC 程序检查模块（语法/模态/安全） | **0 / 0** | ❌ |
| 案例检索（方案里 AI 节点的"相似案例"） | **0 / 0** | ❌ |
| 工艺知识 / 知识图谱 / 工艺设计 | 3 / 4 / 4 片段（1~3 篇） | ⚠️ 极薄 |
| 后处理 | **1 片段 / 1 篇** | ⚠️ |
| 仿真 / 数字孪生 | 229 / 288 片段（26 / 16 篇） | ✅ 但偏车间级 |
| 磨损 / 热误差 / 切削力 / 参数优化 | 382 / 148 / 132 / 65 片段 | ✅ |

结论：**这 44 篇是"加工机理 + 监测/优化/仿真/补偿"，不含"AI 辅助工艺编制 + NC 代码工程"那一层。**
所以三道题设计成 **2 道覆盖内 + 1 道缺口探针**——探针题的"答不出来"是**预期结果**，
它给出的"要补哪类资料"比一份漂亮答案更有用。

### 2.2 使用日志：机器填它知道的，人填只有人知道的

`--log` 每次运行追加一行 JSONL，自动记：提问 / 时间 / 候选数 / 调用次数 / prompt / completion /
缓存命中 / 耗时 / 是否降级及原因 / 引用三档计数 / 无引用条目数。

而 `adopted` 与 `note` 两格**故意留空**：

> "这次答案帮上忙还是帮倒忙"只有使用者知道。G3 验收要的正是这两个字段，
> 所以**机器不替人下结论**——日志里那两格空着，就是提醒"还没评过"。

另外：日志放 `data/`（已 gitignore）。**真实研究问题不必默认提交到公开仓库**——
这也决定了"证据"分两层：机读日志留在本地，可公开的报告进 `eval/`。

### 2.3 定向优化①：语境保真（T35）

引用校验管"没编"，管不了"用错"。三条真实例子：

| 答案里的说法 | 原文 | 风险 |
| ------------ | ---- | ---- |
| `S=60 r/min、af=0.05 mm/r、ap=0.02 mm` | 逐字一致 | 但那是**超精密慢刀伺服车削**（单点金刚石车刀、7050 铝）的转速，搬到常规车削会出事 |
| 加工时间缩短 16% | 逐字一致（图 9 标注） | 该数值在原文是**转引文献[85]**的结果 |
| "智能体具备自主决策/协同交互/自适应学习" | 逐字一致 | 但那是**产线调度的 RL 智能体**（把工人抽象成智能体），与 LLM 智能体不是一回事 |

改法：`ANSWER_PROMPT` 规则 1 补两条——引用具体数值/参数/做法必须**带原文适用语境**；
术语可能不同义时必须**显式说明差异**，不得当同一概念回答。

### 2.4 定向优化②：参考文献段标记（T36）

文献表是"对任何查询都语义相近"的天然噪声（实测两次被当候选）。做法分三层：

1. **建索引时判定**：`Chunk.is_reference`（书目专属特征 ≥ 4 条）；
2. **检索默认排除**：`exclude_references=True`，留 `--include-references` 复现；
3. **页级多数表决**：同一 `(文件, 位置)` 下过半片段被标记 → 整页按文献表处理
   （文献表常被切得很碎，实测某页 10 个片段、每个只剩 1~2 条特征）。

## 3. 实测记录

### 3.1 三次真实使用

| 题 | 候选 | plan / answer completion | 引用（精确/缺定位/**编造**/无引用） | 耗时 | adopted |
| -- | ---- | ------------------------ | ----------------------------------- | ---- | ------- |
| 刀具磨损监测 → 车间刀具管理与换刀决策 | **5**（盘点判"已足够"，**省掉一轮补检**） | 1380 / 1755 | 17 / 0 / **0** / 0 | 27.5s | ✅ |
| 切削速度/进给量/切深的选择与优化 | 10（补检过） | 726 / **5427** | 18 / 0 / **0** / 0 | 32.5s | ✅ |
| LLM/智能体辅助数控工艺方案编制 | 10 | 301 / 2609 | 15 / 0 / **0** / 0 | 20.1s | ❌ |

两个值得记的细节：

- 第 2 题的 answer completion 是 **5427**——**T32 那次把预算从 4096 提到 8192，这题当场回本**；
- 第 1 题的盘点判"候选已足够"，于是**没有做补检**（省一轮检索）——多跳不是"永远走满两轮"。

### 3.2 引用回查：5 条全对，但读到三处语境问题

数值/表述类结论最容易"看着对、其实不对"，所以我把 5 条拉回原文逐字比对：
**全部一致，没有转录错误**。但读的时候发现 2.3 那三处语境漂移——**问题不在数据，在解读**。

### 3.3 第 3 题："帮倒忙"长什么样（值得收藏的样本）

模型主动声明：

> "资料中没有大语言模型（LLM）辅助数控工艺方案编制的研究；候选片段仅涉及数字孪生驱动的
> 工艺系统、强化学习生产线调度智能体与切削参数优化，故未列任何 LLM 相关结论，
> **也未做跨主题拼凑**。"

但它**仍然用相邻领域内容填满了四段**（数字孪生工艺系统、RL 调度智能体），
并且在"方法对比"里自己标注了"局限：面向产线调度，非工艺方案编制"。

结论：**声明是诚实的、内容是相邻的**。所以 `adopted=false`：
它能告诉你"本库没有"，但不能拿它的四段当"LLM 辅助工艺编制的研究现状"。
这是"帮倒忙"最典型的形态——**不是说错话，而是让人误以为有答案**。

### 3.4 参考文献段判据：我自己踩的坑

| 版本 | 判据 | 结果 |
| ---- | ---- | ---- |
| 第一版 | 「`[数字]` 紧跟字母/汉字」+「密度 ≥0.5 条/百字」 | **664 / 2501（26.6%）**，单篇最多 76 条，**散布在正文各页** |
| 第二版 | 书目专属特征：`[J]/[C]/[M]`、`doi.org/10.`、`et al`、英文"编号. 姓, 首字母."、`[CrossRef]` | **657 / 2501**（含页级表决），命中页集中在论文末尾；英文论文也覆盖 |

为什么第一版会错：中文综述正文里"XING Q Q 等[18]提出…"这种句子满篇都是，
而我挑的特征（`[数字]`+作者）**正文里也有**，密度阈值轻易被撑破。
**判据的特征必须挑"目标里几乎不会出现、而噪声里才有的"**——这是本周最值钱的一条教训。

### 3.5 成本

三次真实使用共 6 次调用：prompt **17,361** / completion **12,198** / 缓存命中 768 token。
按第 19 周实测的低谷价量级（20 次重排调用约 9.4 万输入 token），
**三次真实使用不到一分钱**。这笔账对"要不要本地部署大模型"是个有用的参照。

## 4. 踩坑

1. **判据自己成了噪声源**（3.4）：特征挑"正文里也会出现的东西"，等于给噪声发通行证。
2. **PDF 抽取的排版噪声**：`et al.` 会变成 `et al .`（点号前带空格），
   严格要求点号紧跟会**整批英文文献都漏掉**。查"为什么这页一条都没标上"才发现。
3. **"回查通过"不等于"能直接用"**（2.3）：校验只能挡编造，语境与术语要人读。
4. **多跳不是越走越好**：第 1 题盘点说"够了"就停，省了一轮；
   如果无脑走满两轮，只会多花钱。
