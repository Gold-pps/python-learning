## 三、放哪、怎么入库

```powershell
# 1) 放进对应子目录（子目录名就是"子主题"，别新建别的名字）
#    data/corpus/AI辅助工艺编制/*.pdf
#    data/corpus/NC代码生成与校验/*.pdf

# 2) 先扫（只解析、不编码、不花钱）——失败为 0 再往下
uv run python -m rag.index scan

# 3) 全量重建（**必须显式给 --backend**，默认 bge 会因缺依赖报错；--report 要跟文件名）
uv run python -m rag.index build --backend fastembed --all --verify --report eval/建库报告-<新篇数>篇.md

# 4) 重跑检索冒烟（离线、0 元）
uv run python -m eval.review_coverage --top-k 5 --max-per-source 2 --out eval/检索冒烟.md
```

**不要跳过第 2 步**：解析失败的文件进了索引只会污染检索，而且事后很难分辨。
