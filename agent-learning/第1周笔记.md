## 1. Agent 的五个组成部分

| 组成 | 作用 | 在代码里的对应 |
| --- | --- | --- |
| 模型 | 理解、推理、生成 | `model="deepseek-flash"` |
| 指令 | 告诉它角色、目标、工作方式 | `Agent(instructions=...)` |
| 工具 | 查资料、算数据、操作文件、访问外部系统 | `@function_tool` |
| 循环 | 提出计划 → 调工具 → 看结果 → 继续行动 | `Runner.run()` 内部的循环 |
| 状态 | 记住上下文、跨轮次推进 | `history` / `to_input_list()` |

一句话：**Agent = 模型 + 指令 + 工具 + 循环 + 状态**。
后面 12 周其实就是在逐一验证这五项——第 2 周验模型与指令，第 3 周验工具，
第 4 周验状态，第 5~7 周验循环之上的编排、护栏与评估。

## 5. 坑与注意

| 坑 | 说明 |
| --- | --- |
| **Python 版本写低了** | 规划里写"安装 Python 3.10+"，但本项目代码实际要求 **≥3.12**：`main.py` 用了 `asyncio.timeout()`（3.11+），`eval_cases.py` 用了 `Path.is_junction()`（3.12+）。文档已于 2026-09-15 统一更正 |
| 目录名与规划不一致 | 规划写 `python学习/agent/`，实际是 `python-learning/agent-learning/`，文档已更正 |
| `.env` 有被提交的风险 | 必须确认 `.gitignore` 里有 `.env`；仓库里还残留过一个 `agent/.env` 副本，属待清理项 |
| 别顺手用 `gpt-*` | 官方文档示例全是 `gpt-*`，照抄会指向 OpenAI，务必换成 `deepseek-flash` |
